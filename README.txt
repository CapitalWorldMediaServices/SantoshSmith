CAPITAL GROUP — SANTOSH SMITH DIGITAL CARD (GITHUB PAGES)

This folder is ready to upload to the ROOT of a GitHub repository.

Files:
- index.html
- capital-card-front.png
- capital-card-back.png

IMPORTANT:
Keep all three files together in the same repository folder (the root).
Do not rename the PNG files unless you also update the filenames in index.html.

PUBLISH:
1. Open your GitHub repository.
2. Choose Add file > Upload files.
3. Upload these three files to the repository root.
4. If index.html already exists, replace it with this version.
5. Commit the changes to the main branch.
6. In Settings > Pages, select Deploy from a branch, branch main, folder /(root), then Save.
7. Wait for the Pages deployment to finish and open the published site URL.

This set preserves the supplied Capital Group front/back PNG artwork and the supplied Santosh Smith contact details.
